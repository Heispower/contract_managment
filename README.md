# 合同管理系统

> 一套在本机或局域网运行的一体化合同业务系统：客商、项目、采购计划、销售/采购合同、出入库、收付款、发票、报关、统计与提醒。当前版本 **2.5.3**。

> 当前部署已移除「销售订单 / 采购订单」菜单与页面；数据库订单表为空。后端订单接口和表结构保留以便以后恢复，合同、出入库、收付款、发票均可独立使用。下文涉及订单的内容为保留能力说明。

> 「其他收入 / 其他支出」菜单与页面也已移除；`other_bill` 表为空，后端接口保留。合同毛利公式仍会在有历史数据时计入这两类金额。

系统用浏览器操作，后端同时提供接口和已构建的页面，数据库是项目目录内的 SQLite 文件，不需要单独安装数据库服务。销售和采购各走一条完整链路，金额、库存、开票、收付款在单据保存或删除时实时重算；报关模块在合同与采购入库之上，继续生成报关物料、报关发票、清关发票和报关要素。

功能与界面以当前代码为准；业务规则的完整设计依据见 [合同管理系统开发文档.md](合同管理系统开发文档.md)。

## 快速开始

1. 双击 `安装依赖.bat`，等待提示「安装完成」（第一次使用，或依赖有变动时）。
2. 双击 `启动.bat`，浏览器会自动打开 `http://127.0.0.1:8001`。
3. 用 `admin / 123456` 登录；用完双击 `关闭.bat`。如果提示密码错误，说明 `data/contract.db` 已使用过，账号以库中数据为准（见 [8.4 登录账号](#84-登录账号)）。

详细步骤、局域网访问和故障排查见 [8. 安装、启动与部署](#8-安装启动与部署)。

## 2. 模块说明

### 2.1 首页（仪表盘）

- 顶部 4 张数量卡：合同总数、已完成合同、客户总数、供应商总数，并显示本月新增或完成率。
- 中部 4 张金额卡：已收款、已开票、已付款、已收票；每张带本月金额和占比进度条。
- 趋势图对比近几个月的销售与采购金额；环形图显示合同状态分布，悬停可看金额与已收付。
- 最近提醒默认显示临近 30 天内及已到期的合同/发票，可切换销售合同、采购合同、销项发票、进项发票。
- 最近合同分销售/采购页签，最近交易分收款/付款页签；查看按钮跳转到对应模块。

### 2.2 商务信息 · 客商

商务信息页分「客商」「项目」两个页签，从顶栏「商务信息」进入；旧的 `/party/list`、`/project/list` 会自动跳到对应页签。

客户与供应商共用一套主数据，用类型区分，保存后类型不可改。

- 列表顶部切换「供应商 / 客户」，新增按钮随之变为「新增供应商 / 新增客户」。
- 字段：编码、名称、简称、类型、税号、银行账号、开户行、账户名称、开户支行、默认税率、开票名称、开票地址/电话、法人、委托代理人、地址、联系人、状态。
- 联系人子表：姓名、电话、是否默认联系人；同一客商至多一个默认联系人。
- 默认税率在新建合同时自动带出，仍可手改。
- 改名后询问「是否同步更新引用此客商的单据？」；确认只改合同、订单、收付款、发票上的名称快照，不改开票名称和税号。
- 删除前检查合同、订单、收付款、发票引用，有引用则提示「后续已生成单据，无法删除。」。
- 支持按编码/名称/税号/银行账号搜索、批量删除、Excel 导入（编码相同则更新）。

### 2.3 商务信息 · 项目

商务信息页的「项目」页签。

- 独立台账，不是合同子项目。
- 字段：项目编号、项目名称、项目类型、项目来源、项目年度、客户名称、开始日期、结束日期、状态、备注。
- 客户名称是手填自由文本，不挂客商 ID，不参与合同客商校验与统计。
- 「关联合同」列实时反查合同上的项目字段，可显示多张合同，不落库。
- 被合同引用时不允许删除；项目状态与合同状态互不影响。
- 合同基本信息可选择项目，带出项目编号、名称、年度。

### 2.4 采购计划

- 同一物料编号在全公司只有一行计划；计划月份、采购序号、计划单号、使用设备都是这一行的属性。
- 列：计划月份、采购序号、物料编号、采购计划单号、使用设备、中文名称、英文名称、规格型号、单位、采购数量、已采购数量、待采购数量、用途、使用部门、库存数量、在途数量、4 个月消耗量、备注。
- 「已采购数量」= 全部采购合同明细中该编号数量之和，实时汇总，不落库；「待采购数量」= 采购数量 − 已采购数量。
- 三种导入模式：按物料编号更新、清空后重新导入、追加；文件内部编号重复的行失败。
- 计划行支持编辑：可修改计划月份、采购序号、计划单号、名称、规格、数量、用途等；物料编号是唯一键，编辑时不可改；采购数量不能小于已采购数量。
- 采购合同保存时按编号核销：计划数量 − 其他合同占用 − 本单数量不能小于 0；采购合同中的物料必须能在计划中找到，否则提示「物料 X 没有采购计划」。
- 被采购合同占用的计划行不能删除；删除计划行不会回改已生成的采购合同。

### 2.5 合同（销售合同 / 采购合同）

两页骨架相同，销售侧读客户，采购侧读供应商。列表一行一张合同，不按物料拆分。

**列表与操作**

- 列：合同编号、合同名称、原合同、合同类型、方向、对方编码/名称、项目编号/名称/年度、业务员、合同状态、归档状态、签订日期、结束日期、计价方式、商品数量、合同税率、不含税金额、合同金额、合同预收/预付、阶段完成数、已收/已付、未收/未付、收付款状态、发货/到货情况、发票收到、操作。
- 补充协议的合同编号带「补」标；合同编号与操作列固定。
- 状态标签：未签订灰、已签订浅蓝、已终止浅红；未归档灰。
- 合同金额合计按当前筛选结果统计；未收/未付大于 0 用红字。
- 行操作：查看/编辑、补充、删除；采购合同另有「复制」。
- 「更多」：批量导出、关联项目、生成收款单/付款单、生成进项发票（采购、单选）、生成销售合同（采购、多选）、生成到货单/发货单（单选）。
- 采购合同工具栏有「生成合同」按 Word 模板输出正式合同；销售合同用工具栏的「生成表单」选择模板输出。

**三个页签**

1. **基本信息**：合同编号（留空自动生成）、名称、性质（主合同/补充协议）、合同类型、项目、对方、业务员、状态、归档（只读）、计价方式、税率、签订/开始/结束日期、内容概述、条款、备注。
   - 采购合同额外有：标的名称、收货地址、收货人、运输方式、交货期限、运费承担、附件说明、验收标准，用于 Word 合同。
   - 新建默认：已签订、固定总价、税率 13%、主合同。
2. **物料明细**：物料编号、中文名称、英文名称、规格、单位、数量、含税单价、含税总价、税率、备注；采购另有计划单号、使用设备。同一合同同一物料编号只能有一行；数量必须大于 0，单价不能小于 0。
   - 可加行、删行、一键清空、「从采购计划选择」、按模板导入物料。
   - 销售合同如果是「由采购合同生成」，可填加价比例批量改单价，也可逐行填价；这种模式只能删行，不能新增物料或改数量。
3. **阶段付款**：阶段名称、比例、计划金额、计划日期、备注、已收/已付；采购加「到货阶段」圆钮，销售加「发货阶段」圆钮。
   - 默认四行：预收款/预付款 30%、进度款 40%、验收款 25%、质保金 5%。
   - **各阶段计划金额合计必须等于合同金额**；手工改任一行时最后一行自动补差，补出负数则保存失败；被收付款单引用的阶段不能删除。
   - 已收/已付只读，由收付款单回写；合同未付 = max(合同金额 − 已付, 0)，阶段剩余 = max(计划金额 − 已付, 0)，两套数分开使用。

**计价方式**

- **固定总价**：行价税合计 = round(签约数量 × 含税单价, 2)，出入库不改合同金额。
- **按实结算**：按该合同累计采购入库（采购）或销售出库（销售）数量 `settled_qty` 重算行金额与合同金额；签约数量 `qty` 不变；阶段计划金额按现有比例重新分摊，尾差进末段。
- 出入库导致合同金额减小时：已下单金额超过新金额则阻止保存；已开票金额超过新金额则「发票收到」置为已收到并禁止继续开票。

**补充协议**

- 行操作「补充」新建一张补充协议，预选最上层主合同，编号按 `原合同号-补1`、`补2` 递增。
- 补充协议有自己的物料、阶段、订单、收付款、发票；金额不并入主合同，统计时按独立合同各算一行。
- 补充协议不限创建者；主合同名下存在补充协议时不能删除主合同。

**到货 / 发货圆钮**

- 采购合同阶段表的「到货阶段」、销售合同的「发货阶段」为整表单选圆钮，默认第一行；插入、删除行时自动联动。
- 付款/收款使该阶段达到计划金额时，弹窗询问是否制作到货单/发货单；确认后打开**未保存**的入库/出库新增页，点保存才改库存。
- 确认或取消都会置位 `arrival_triggered` / `ship_triggered`，同一阶段不再重复询问。

### 2.6 订单（本部署未启用）

当前部署已移除销售订单、采购订单的菜单和页面，数据库订单表为空。以下内容描述后端保留能力，界面暂不提供入口：

- 一张合同同时最多一张未删除订单；订单号默认 `order` + 合同编号，如 `orderCG-2026-001`。
- 订单按物料展开，一张订单多个物料显示多行；物料从合同复制，可改数量、含税单价，金额不能超过合同金额。
- 采购订单显示累计到货，销售订单显示累计发货；未齐显示「已经到货/发货 XX 单位」，齐了显示「到齐/发齐」。
- 新增时若没有可下单的同方向已签订合同，提示先去录入合同；未签订、已终止合同不能下单。
- 关闭订单只校验订单自身物料行到齐/发齐，未齐提示「订单尚未完成，无法关闭」；已关闭可取消关闭。
- 订单是执行辅助单据，**不构成出入库数量上限**；合同仍可按自身数量继续出入库。
- 支持导入、导出、批量删除；删除后合同恢复为可下单状态。

### 2.7 仓储管理

**采购入库 / 销售出库**

- 新增入口有三个：本页新增；合同列表勾选一张后点「生成到货单 / 生成发货单」；到货/发货阶段确认后打开未保存的新增页。后两个自动带上合同和物料，点保存才落账、才改库存。
- 单据头：单据编号、单据日期、合同、对方（随合同带出）、仓库、备注。
- 物料从合同带出，未实际到货/发货的行删掉，留下的行改实际数量；数量必须大于 0。
- 同一合同可多次入库/出库；累计数量不能超过该合同物料签约数量；销售出库还不能超过当前库存。
- 保存、修改、删除后按「该仓库该物料未删除入库之和 − 未删除出库之和」整单重算库存，结果小于 0 整单回滚。
- 如存在历史订单，同时刷新其到货/发货显示；按实结算合同重算金额与阶段。
- 已到齐/已发齐的物料，下次新增不再列入清单。

**库存余额**

- 维度：公司 + 仓库 + 物料；字段：物料编号、仓库、商品编码、商品名称、单位、数量、成本。
- 只读，无新增按钮，也不提供直接修改数量的编辑入口；数量和成本只能由采购入库/销售出库重算，避免与出入库单据不一致。需要纠正库存时，录入对应的入库或出库单。
- 成本取该仓库该物料最近一张采购入库（先比单据日期，再比创建时间，再比 ID）的含税单价；没有入库记录时为空。销售出库不改变成本。
- 库存不为零不能删除，也不能停用对应仓库。

**调拨记录 / 盘点记录**

- 仅业务留痕台账，不自动更新库存余额，也不做 WMS 过账。
- 调拨：单号、日期、调出仓库、调入仓库、物料、数量、备注；支持新增、编辑、删除。
- 盘点：单号、日期、仓库、物料、账面数量、实际数量、差异（实际 − 账面）、备注；支持新增、编辑、删除。编辑时账面数量保留原盘点快照，实际数量可改，差异随之重算。
- 需要按盘点差异调整库存时，走采购入库/销售出库单据。

### 2.8 结算管理

**收款单 / 付款单**

- 收款单只对销售合同，付款单只对采购合同。
- 新增顺序：先选客户/供应商 → 可选用物料缩小合同范围 → 选合同（显示剩余可收/付）→ 勾选阶段（剩余大于 0）→ 每个阶段填本次金额 → 保存。
- 每个阶段单独一张单据；一次勾选多个阶段时，单号在原单号后加 `-01`、`-02` 拆成多张。
- 金额必须大于 0 且不超过该阶段剩余；账户来自资金账户，新增只显示启用账户，编辑历史单据保留原停用账户显示。
- 保存、修改、删除后回写阶段已收付、合同已收付合计、未收付、收付状态，并触发到货/发货询问。
- 列表可按客商、合同筛选，支持导入、导出、行内编辑、删除、批量删除。

**其他收入 / 其他支出（本部署未启用）**

- 菜单与页面已移除，`other_bill` 表为空；后端接口保留。
- 合同毛利公式仍为「销售合同金额 − 采购合同金额 − 其他支出 + 其他收入」，有历史数据时会继续计入。

**待收款 / 待付款**

- 只读汇总，不能新增、导入、删除。
- 范围：有未付阶段的已签订合同，以及已终止但仍有未付阶段的合同；未签订合同不出现。
- 月份下拉可多选：本月未付/未收、下月、未来 2–5 月、半年后；逾期阶段归入本月；计划日期为空的阶段只在不选月份时出现，显示「未设截止日」。
- 列：合同编号、合同名称、对方、余额、收/付款详情（逐阶段换行）、备注、逾期。
- 右上角合计显示「未付/未收阶段 N 条，合计 ¥Y」；底部分页按合同行计，两者分开。
- 导出带逐阶段详情与备注。

### 2.9 发票（销项 / 进项）

- 销项对销售合同与客户，进项对采购合同与供应商，两页同一套列表与编辑逻辑。
- 列表列：单据日期、单据编号、发票号码、发票类型、客商编码/名称、不含税金额、税额、价税合计、商品数量、合同编号/名称、付款状态、付款进度、创建人。
- 新增：先选客商；再选该客商名下未终止的合同；发票号、发票日期必填；发票类型默认增值税专用发票。
- 选中合同后，按「合同物料 − 以往已开票数量」带出剩余行；匹配只认物料编号；没有剩余时可手加行，但手加行的物料编号必须已存在于该合同物料。
- 明细可改数量、含税单价、不含税金额、税额、税率；数量必须大于 0。直接改不含税金额或税额时，价税合计 = 不含税 + 税额，并反算含税单价，保证行内三项自洽。
- 保存双层校验：
  1. **数量层**：同合同同物料累计开票数量（含本单）≤ 该物料签约数量；
  2. **金额层**：该合同累计开票价税合计（含本单）≤ 合同金额。
- 发票号码公司内唯一；换合同编辑时旧合同与新合同都重算。
- 合同「发票收到」状态：无发票 / 部分 / 已收到。
- 支持导入、导出、批量删除、按模板生成 Word/Excel 表单。

### 2.10 报关系统

报关模块在合同与仓储之上，形成一条独立的数据链：**采购入库 → 报关物料 → 报关发票 / 清关发票 / 报关要素 → 导出报关资料**。原始物料只录一次，后续单据都从报关物料生成。

**报关物料清单**

- 采购入库保存时自动同步生成报关物料；同一条入库明细对应一条报关物料。
- 必填项：合同号、箱单号、物料大类、物料编号、物料名称、产地、使用设备、毛重、净重、体积、尺寸；缺项会在详情中标红并阻止保存。
- 状态：是否已生成报关发票、清关发票、报关要素，以及「已报关 / 未报关」。
- 支持按入仓单号、供应商、合同号、箱单号、物料大类、物料编号、名称、使用设备筛选；可隐藏已生成某类单据的物料。
- 批量赋值：物料大类、集装箱号、提单号、船名/航号、箱单号、产地、使用设备、出发港、目的港、收货人、付款条款、HS Code、申报要素、入仓单号、备注、特殊申报。
- 批量导入：下载模板回填后上传，按物料编号 + 入仓单号匹配，整批校验通过才写入。
- 选中物料后可生成报关发票、清关发票或报关要素；已被发票/要素引用的物料不能删除，需先解除关联。

**报关发票**

- 仅可选择已有采购入库的报关物料；同一物料不能重复生成报关发票。
- 按物料大类/申报名称汇总；特殊申报物料单独成行。
- 头部：发票编号（可自动生成）、发票日期、船名/航号、集装箱号、提单号、出发港、目的港、箱单号、合同编号、PO NO.、汇率、收货人、付款条款、报关要素。
- 三个页签：主页面、物料大类详情、物料明细表；金额按人民币计，美元金额按汇率换算。
- 可关联报关要素；导出 Excel（`报关发票.xlsx` 模板），或一键导出含附件的 ZIP。
- 支持编辑、删除、批量删除。

**清关发票**

- 从报关物料生成，要求物料有对应采购入库，且未生成过清关发票。
- 头部：发票号（可空，空则显示「无发票号」）、日期、船名/航号、集装箱号、提单号、出发港、箱单号、汇率、人民币合计、美元合计。
- 三个页签：主表、物料大类清单（品名、规格、数量、单位、包装件数、毛重、净重、尺寸、入仓单号）、物料明细（中文名、英文名、规格、数量、单位、人民币单价/总价、换算美元、PO、备注）。
- 导出 Excel（`清关发票.xlsx` 模板）或 ZIP。

**报关要素**

- 关联一张报关发票生成；同一发票只能关联一次。
- 按申报名称分组，同一申报名称共用一套申报要素；产品行只区分产品名称、型号、货源地。
- 字段：序号、HS Code、申报名称、产品名称、型号、申报要素、货源地、数量、匹配来源。
- 可从 HS Code 库自动匹配（精确或相似度推荐），也可手工填写；「AI 检查」调用 DeepSeek 判断申报名称、HS Code、要素是否匹配；保存时对比报关发票与报关要素的名称/数量差异并提示。
- 导出 Word 表单（`{{报关发票编号}}-报关要素.docx`）与附件。

**支撑资料**

- 基础资料中的「HS Code 库」：HS Code、申报名称、产品名称、申报规格、报关要素、描述、状态；支持导入。
- 基础资料中的「汇率库」：年、月、币种、汇率、生效日期；报关发票/清关发票按开票月份取汇率。
- 基础资料中的「Deepseek」：启用开关、接口地址、API Key、模型、超时、温度、思考模式；AI 不可用时只做本地必填检查，不阻断业务保存。

### 2.11 统计

- **经营概况**：销售合同金额、累计销售金额、已收款、已开票、采购合同金额、累计采购金额、已付款、合同毛利。
- **客户统计 / 供应商统计**：按已签订合同汇总合同数量、合同金额、已收/已付、状态；已收付达到合同金额为「已完成」，否则「进行中」。
- **供应商往来统计**：上容器按供应商汇总采购金额、已付款、未付款、欠款、是否有逾期、合同数量；点供应商后下容器显示合同明细、付款状态、逾期状态、逐阶段付款信息，并按逾期优先排序。
- 金额统计只计未删除且状态为「已签订」的合同；未签订、已终止不计入。
- 合同毛利 = Σ 已签订销售合同金额 − Σ 已签订采购合同金额 − Σ 其他支出 + Σ 其他收入。它是合同金额口径的毛利，不含库存成本、期间费用和税费。

### 2.12 到期提醒

- 四个页签：销售合同到期、采购合同到期、销项发票到期、进项发票到期。
- 合同到期日取结束日期，发票到期日取发票日期；结束日期为空的合同不提醒，已到期（日期 ≤ 今天）且未处理的单据进入列表。
- 顶部显示各页签未处理条数；顶栏铃铛数字为四个页签未处理数之和。
- 「检查提醒」重新判定并刷新；「确认」「忽略」写入处理记录，处理过的不再算未处理。
- 首页另外展示临近 30 天内及已到期的提醒，方便提前处理。

页内页签切换，是各下拉、模板和参数的来源。

### 2.14 组织管理

- **用户**：员工编号、登录名、中文姓名、初始密码、角色文本、状态、可访问公司（多选）、默认公司、导入覆盖权限。
- 员工编号全局唯一，是业务认人的唯一值；登录名只用于登录；中文姓名只用于显示，改姓名后单据列表实时显示新姓名。
- 用户列表按当前公司过滤；admin 可见全部公司。admin 不能删除。
- 被合同、订单、收付款、发票、出入库等单据引用（业务员/创建人/更新人）的用户不能删除，只能停用；停用后不能登录，也不能被新选为业务员。
- 「修改密码」为管理员重置，不需要旧密码；用户本人在右上角改密需要旧密码。
- **角色 / 部门 / 岗位**：编码、名称、备注的纯组织字典，不授权、不控制菜单、不限制数据范围；本版本不做 RBAC。

### 2.15 设置

- **顶栏**：左侧公司简称点击回首页；横向菜单进入各模块并高亮当前项；右侧提供亮色/暗色切换、全屏、通知铃铛和头像菜单（修改密码、选择公司、退出登录）。
- **登录日志**：用户、登录时间、IP、结果；只记录成功登录，IP 当前固定为 `127.0.0.1`。
- **操作日志**：用户、操作、时间、摘要；覆盖合同、订单、发票、收付款、出入库、其他收支、调拨/盘点、客商、项目、采购计划、基础资料、导入、客商改名同步、重置密码、切换公司、初始化演示数据等关键动作。
- **安全设置**：密码最小长度、登录失败锁定次数、登录锁定时长（分钟）；登录与改密都读取这里的配置。管理员可在此清空全部业务数据（输入「清空全部数据」确认，当前账号与公司保留）。

### 2.16 列表页统一交互

除首页和报关要素编辑页外，多行数据页共用同一套骨架：

- 自上而下六块：全局顶栏、页面标题、搜索筛选、操作工具栏、数据表格、底部合计与分页。
- 筛选区支持查询、重置、展开/收起；收起时只保留最前面的几项，展开显示全部条件。
- 工具栏左侧放当前页的主按钮（新增、导入、批量删除、更多），右侧放合计提示和导出、搜索区域、刷新、行宽（宽松/中等/紧凑）、列设置。
- 表格最左复选框、最右操作列固定，中间列可左右滚动；表头与合计行固定，只有数据行滚动。
- 列设置可勾选显隐、上下移动、固定/取消固定；合同编号、发票号码等固定列不可隐藏，用户改过的列顺序和显隐会记住。
- 金额右对齐、保留 2 位小数；未收/未付大于 0 显示红字；状态用彩色标签（已签订浅蓝、未签订灰、已终止浅红、已归档浅绿）。
- 默认每页 50 条，可调整；合计行按当前筛选结果统计，不是当前页小计。

## 3. 三条核心业务链

### 3.1 销售链

1. 在「商务信息 → 客商」建客户，维护默认税率、开票名称、税号、地址、默认联系人。
2. 组织管理建业务员；基础资料维护合同类型、收款账户、仓库。
3. 新建销售合同：选客户后带出税率；录入物料，合同金额取明细含税合计；维护收款阶段和发货阶段圆钮。
4. 需要变更时点「补充」生成补充协议，单独走自己的收款和发票。
5. 做收款单：先选客户、再选合同、勾阶段，金额不超阶段剩余；保存后合同已收、未收、阶段完成数、收款状态一起变。
6. 收款达到发货阶段时确认生成销售出库：删掉未发货行、改实际数量，保存后才减库存。
7. 做销项发票：按合同未开票物料带出，保存后合同「发票收到」和已开票金额变化；再次开票自动扣减已开数量。
8. 首页、客户统计、经营概况读取新的销售金额、已收款和已开票数据。

### 3.2 采购链

1. 导入采购计划：物料编号唯一，已采购为 0，待采购等于采购数量。
2. 建供应商，默认税率带进采购合同。
3. 新建采购合同：从采购计划选料或按编号导入；保存时核销计划，超出整单失败；阶段表自动把到货圆钮点在第一行。
4. 做付款单：按采购合同阶段付款，回写已付款和付款状态；付到到货阶段时确认生成采购入库。
5. 采购入库保存后重算库存；按实结算合同同步重算金额。
6. 做进项发票：按采购合同未开票数量开票，回写「发票收到」。
7. 供应商统计、供应商往来统计按采购合同金额、已付款、未付款和逾期展开。

### 3.3 报关链

1. 采购入库保存，自动生成报关物料；也可以在报关物料清单批量导入/回填缺失字段。
2. 在报关物料清单勾选物料，生成报关发票：按物料大类汇总，特殊申报单独成行，带出船名、集装箱、港口、PO、汇率等。
3. 同一批物料可生成清关发票：维护主表、大类清单、明细、汇率与美元金额。
4. 报关发票生成后，可关联报关要素：按申报名称分组，匹配 HS Code 与申报要素，必要时用 AI 检查。
5. 核对差异，保存报关要素；在基础资料维护 HS Code 库和月度汇率。
6. 导出报关发票 Excel、清关发票 Excel、报关要素 Word，或一键导出含附件的 ZIP。

### 3.4 回写矩阵

| 触发动作 | 必须重算 / 回写 |
| --- | --- |
| 收付款单保存/修改/删除（含批量） | 阶段已收付、阶段状态、合同已收付合计、未收付、收付款状态、到货/发货触发标记 |
| 发票保存/修改/换合同/删除（含批量） | 合同已开票金额、「发票收到」、未开票数量；换单时新旧合同都重算 |
| 采购入库/销售出库保存/修改/删除（含批量） | 库存余额、对应订单到货/发货显示、按实结算合同金额与阶段 |
| 订单保存/换合同/删除（含批量） | 合同已下单金额；删除后合同恢复可下单 |
| 采购合同保存/修改/删除 | 采购计划核销校验；删除后计划占用随明细减少 |
| 合同改金额/改数量/删物料 | 校验不低于已下单、已开票、已出入库数量；阶段金额合计必须等于合同金额 |
| 客商改名/导入覆盖名称 | 用户确认后同步合同、订单、收付款、发票的名称快照 |
| 删除合同/客商/项目/商品/用户/仓库/账户 | 先做引用检查，有后续单据则拒绝；删除后按需重算 |
| 提醒「检查提醒」/「标记」 | 只读判定 + 处理记录；不改合同、发票金额 |

所有回写与主操作在同一事务内完成；任一步失败整单回滚，不会先落单再补算。

## 4. 关键业务规则

### 4.1 金额与精度

全链路使用 `Decimal`，禁止浮点累加；税率按百分比数值存储（13 表示 13%），参与运算时取 `税率 / 100`。

| 项目 | 公式 |
| --- | --- |
| 行价税合计（行主值） | `round(数量 × 含税单价, 2)`，先落定到分 |
| 行不含税金额 | `round(行价税合计 ÷ (1 + 税率/100), 2)`，由主值反算 |
| 行税额 | `行价税合计 − 行不含税金额`，尾差全部吸收在税额 |
| 合同金额 | 有物料：Σ 行价税合计；无物料：手填含税金额 |
| 合同金额（不含税） | 有物料：Σ 行不含税金额；无物料：合同金额 ÷ (1 + 税率/100) |
| 合同已收/已付 | Σ 各阶段回写的已收/已付 |
| 合同未收/未付 | `max(合同金额 − 已收/已付, 0)` |
| 阶段剩余 | `max(阶段计划金额 − 阶段已收/付, 0)` |
| 订单金额 | Σ 订单行含税总价 |
| 待采购数量 | 采购计划数量 − Σ 采购合同该编号数量 |
| 发票价税合计 | Σ 明细行价税合计 |

示例：数量 3、含税单价 100、税率 13% → 行价税合计 300.00，不含税 265.49，税额 34.51，三项相加恒等于 300.00。

### 4.2 合同金额与阶段

- 新建合同带出四行默认阶段：预收款/预付款 30%、进度款 40%、验收款 25%、质保金 5%。
- **Σ 阶段计划金额 = 合同金额**，精确到 2 位；不相等保存失败并提示差多少。
- 手工修改任一阶段计划金额时，最后一行自动补成「合同金额 − 其余行之和」；补出负数则失败，不写入负数。
- 比例只作分摊依据，不强制合计 100%；改比例会按合同金额重算计划金额，改计划金额不反算比例。
- 被收付款单引用的阶段不能删除；阶段删光后到货/发货圆钮无选中，再加行时自动点第一行。

### 4.3 按实结算

- 采购合同按该合同累计采购入库数量、销售合同按累计销售出库数量计算 `settled_qty`；`qty` 始终是签约数量，不被出入库改写。
- 行金额 = `round(settled_qty × 含税单价, 2)`；合同金额 = Σ 行金额。
- 合同金额变化后，阶段计划金额按现有比例重摊，尾差进最后一个阶段；比例合计为 0 或全空时按阶段数均分。
- 出入库保存顺序：先数量校验（累计 ≤ 签约数量、出库 ≤ 库存），再按实结算重算与越界校验，全部通过才写入；任一失败整事务回滚。
- 金额减少导致订单越界时阻止出入库；导致发票越界时置「发票收到 = 已收到」并禁止继续开票。

### 4.4 发票勾稽

- 数量层与金额层必须同时满足：同合同同物料累计开票数量 ≤ 签约数量；同合同累计开票价税合计 ≤ 合同金额。
- 单价可以改，所以「数量没超但金额超」和「金额没超但数量超」都会各自失败。
- 发票号码公司内唯一，重复提示「发票号码已存在」。
- 手加行只能使用合同内已有的物料编号；同一发票同一物料只能一行。
- 「发票收到」：没有任何发票为「无发票」；价税合计未盖住合同金额为「部分」；达到或超过合同金额为「已收到」。

### 4.5 库存

- 库存数量 = 该仓库该物料未删除采购入库数量之和 − 未删除销售出库数量之和。
- 新增、修改、删除、批量删除都走同一套整单重算，不在旧余额上做增量加减；结果为负整单回滚。
- 成本取最近一张入库单该物料的含税单价（日期 → 创建时间 → 单据 ID）；没有入库记录时为空，销售出库不改变成本。
- 采购入库只刷新采购订单到货显示，销售出库只刷新销售订单发货显示；两边都重算库存。

### 4.6 采购计划核销

- 同一物料编号全公司只有一行采购计划。
- 已采购数量 = Σ 全部采购合同物料该编号数量，实时汇总、不落库；没有占用余量表。
- 采购合同保存/修改时逐编号校验「计划数量 − 其他合同占用 − 本单数量 ≥ 0」，超出整单失败并提示超出多少；修改时排除本单旧行。
- 采购合同中的物料必须存在于采购计划中；手填、导入、从计划选择三个入口同一规则。
- 删除采购合同后，计划占用随明细删除自动减少；删除计划行时若已被采购合同占用则拒绝。

### 4.7 订单（本部署未启用）

当前部署未启用订单界面，订单表为空；本节为后端保留规则。合同、出入库、收付款、发票均不依赖订单：

- 一张合同同时最多一张未删除订单；订单号生成后不再修改。
- 订单金额不能超过合同金额；订单不回写合同金额，不占采购计划，不直接触发出入库。
- 关闭订单只校验订单自身物料行到齐/发齐；关闭后合同仍按自身剩余额度出现在收付款与发票下拉，取消关闭可恢复。
- 订单不构成出入库数量上限，合同仍可按自身数量继续出入库。

### 4.8 编号规则

| 单据 | 规则 |
| --- | --- |
| 销售合同 | `XS-YYYY-NNN`，如 `XS-2026-001`；留空自动生成 |
| 采购合同 | `CG-YYYY-NNN`，如 `CG-2026-001` |
| 补充协议 | `原合同编号-补1`、`-补2` 递增 |
| 订单 | `order` + 合同编号，如 `orderCG-2026-001`；冲突时追加 `-R01`、`-R02` |
| 采购入库 / 销售出库 | 手填，或 `RK-YYYYMMDD-001` / `CK-YYYYMMDD-001` |
| 进项发票 / 销项发票 | 手填，或 `JX-YYYYMMDD-001` / `XX-YYYYMMDD-001` |
| 付款单 / 收款单 | 手填，或 `FK-YYYYMMDD-001` / `SK-YYYYMMDD-001` |
| 其他支出 / 其他收入 | 手填，或 `ZC-YYYYMMDD-001` / `SR-YYYYMMDD-001` |
| 调拨 / 盘点 | 手填，或 `DB-YYYYMMDD-001` / `PD-YYYYMMDD-001` |
| 报关发票 | 手填，或 `BG-YYYYMMDD-001` |
| 采购计划序号 | 保持导入原值，不重编 |

所有单号在公司内唯一；手填重复会提示「编号已存在」，自动生成遇冲突会递取流水。

### 4.9 状态流转

| 实体 | 状态 | 允许的流转 |
| --- | --- | --- |
| 合同 | 未签订 / 已签订 / 已终止 | 未签订 → 已签订；未签订 → 已终止；已签订 → 已终止；已终止为终态 |
| 订单 | 未关闭 / 已关闭 | 未关闭 → 已关闭（物料到齐/发齐）；已关闭 → 未关闭（取消关闭） |
| 客商、账户、仓库、合同类型、商品分类、用户 | 启用 / 停用 | 双向；停用有前提条件 |
| 收付款、发票、出入库、其他收支、调拨、盘点 | 无状态 | 新增、修改、删除 |
| 合同归档 | 未归档 / 已归档 | 本版本无归档入口，恒为未归档 |

未签订和已终止的合同都不能新建订单、收付款、发票、出入库；只有已签订合同出现在这些下拉中。待收款/待付款是唯一例外，仍列出已终止合同未付完的阶段。

### 4.10 删除与引用检查

删除前先检查后续单据，有引用时统一返回「后续已生成单据，无法删除。」。

| 删除对象 | 检查 |
| --- | --- |
| 客商 | 合同、订单、收付款、发票任一引用 |
| 项目 | 被合同的项目字段引用 |
| 合同 | 名下有订单、出入库、收付款、发票（按方向）；主合同名下有补充协议也不能删 |
| 采购计划行 | 被采购合同物料占用 |
| 商品 | 被合同物料、订单、发票、库存、出入库使用 |
| 商品分类 | 仍有商品使用 |
| 用户 | 被单据作为业务员/创建人/更新人引用；只能停用 |
| 资金账户 | 被收付款、其他收支引用 |
| 仓库 | 被出入库、库存、调拨、盘点引用，或库存不为零 |
| 合同类型 | 不做引用检查，建议停用替代 |

订单、收付款、发票、出入库本身不检查下游引用，删除后按回写矩阵重算。

### 4.11 并发控制

- 所有可修改单据带 `version` 乐观锁：打开编辑时读取版本，保存时回传；库中版本不一致返回「数据已被他人修改，请刷新」。
- 批量删除按 `items: [{id, version}]` 逐条比对，任一条冲突整批回滚。
- 导入覆盖已有记录同样逐行携带版本，冲突行计失败，其余行正常写入。
- 额度型资源（库存、采购计划、可下单金额、可开票金额、阶段可收付金额）不只靠 `version`：SQLite 写事务使用 `BEGIN IMMEDIATE` 串行化，后到的事务等到前一个提交后再读最新值校验，避免两张不同单据同时争同一额度把库存/开票/计划冲破。

### 4.12 权限与公司隔离

- 业务单据只有创建者能修改；非创建者提交返回「无权修改，仅创建者可修改」，可以查看。
- 补充协议例外：新增和修改不限创建者，也不限主合同创建者。
- 系统级动作（客商改名同步快照、导入覆盖、服务端回写计算字段）不受创建者限制，但仍递增版本、记录更新人。
- 普通用户执行导入只能新增或覆盖自己创建的记录；覆盖他人记录需要「导入覆盖」权限（admin 天然拥有，其他用户由 `can_import_overwrite` 控制）。
- 用户可归属多家公司，登录时从可访问公司中选择当前公司；切换公司后列表、统计、业务员和组织资料一起切换。
- 服务端从登录会话取当前公司，客户端传的 `company_id` 只做一致性校验；不一致返回 403，不能靠改参数跨公司取数。
- 创建者限制主要覆盖客商、项目、采购计划、合同、订单、仓储单据、收付款、其他收支、发票、商品；公司、资金账户、仓库、合同类型、用户/角色/部门/岗位和安全设置不套用。

### 4.13 审计与安全

- 密码只存 Argon2id 哈希；登录失败按安全设置计数并锁定，到期自动解锁，成功登录清零。
- JWT 有效期 24 小时；管理员停用用户、重置密码或用户本人改密会递增 `auth_version`，旧 token 立即失效。
- 登录写登录日志；关键增删改、导入、改名同步、重置密码、切换公司写操作日志。
- 登录日志当前只记录成功记录，IP 固定为 `127.0.0.1`，属于本机演示行为；正式部署应取真实客户端 IP。
- 「忘记密码」只提示邮件已发送，不会真的发信，也不会改密码；需要管理员重置。

## 5. Excel 导入

各列表工具栏的「导入」打开本页导入页，步骤为：**下载模板 → 上传文件 → 解析预览 → 确认执行 → 查看结果**。预览会逐行标出可导入/失败及原因，确认后仅写入通过的行（采购计划「清空后重新导入」为整批校验、整批替换）。

| 模块 | 模板/模式 | 说明 |
| --- | --- | --- |
| 销售合同 / 采购合同 | 头 + 明细；覆盖现有物料 / 追加到现有物料 | 合同头字段 + 物料明细；采购合同按编号核销计划，覆盖导入先做越界校验 |
| 销售订单 / 采购订单 | 头 + 明细 | 源合同已有未删除订单的行失败；订单号冲突按唯一约束处理 |
| 销项 / 进项发票 | 头 + 明细 | 同一发票号码多行合并为一张发票；同号头字段不一致整组失败；已存在号码不覆盖 |
| 收款单 / 付款单 | 一行一个阶段 | 按阶段序号定位；只有阶段名称时名称必须唯一；多行按行拆单 |
| 客商 | 供应商 / 客户模板 | 编码相同则更新；覆盖他人记录需导入覆盖权限；更新时保留原默认税率 |
| 采购计划 | 按编号更新 / 清空后重导 / 追加 | 文件内编号不能重复；清空重导先校验占用再替换 |
| 商品 | 商品模板 | 按物料编号更新 |
| 入仓单 | 入仓模板 | 生成入仓单与报关物料 |
| HS Code | HS 模板 | 导入 HS Code 库 |
| 报关物料回填 | 专用模板 | 按物料编号 + 入仓单号匹配，整批校验通过才写入 |

通用规则：

- 支持 `.xlsx` 和 `.xls`，文件不超过 10MB。
- 解析只读单元格值，不执行公式；以 `=`、`+`、`-`、`@` 开头的文本去掉前导字符后按文本保存，不置空、不当公式执行。
- 同一用户、同一公司、同一模块、同一导入模式、同一文件内容重复提交，直接返回上一次结果，不重复落库。
- 解析失败提示「文件解析失败，请检查模板格式或必填项」；格式/大小错误提示「文件格式不正确」/「文件大小超过限制」。

## 8. 安装、启动与部署

### 8.1 环境要求

Windows 本机使用，需要：

- Python 3.10 或更高版本（带 `pip`、`venv`）
- Node.js 18 或更高版本（带 `npm`）
- 首次安装可联网下载 pip/npm 包
- 不需要单独安装数据库；SQLite 随 Python 内置

在命令行执行下面两条，能打出版本号即可：

```bat
python --version
node --version
```

### 8.2 首次安装

1. 打开项目文件夹（包含 `安装依赖.bat`、`backend`、`frontend` 的那一层）。
2. 双击 `安装依赖.bat`。
3. 脚本依次完成 8 步：
   - 检查 Python 3.10+，缺失时尝试用 winget 安装；
   - 检查 Node.js 18+，缺失时尝试用 winget 安装；
   - 停止占用端口的旧服务；
   - 在项目目录创建 `.venv`；
   - 把 Python 依赖装进 `.venv`（默认源失败自动切清华镜像）；
   - 安装前端依赖并执行 `npm run build`，生成 `frontend/dist`；
   - 创建 `data`、`data/uploads` 目录；
   - 生成字段清单并初始化数据库。
4. 看到「安装完成」后按任意键关闭窗口。

依赖全部装在项目目录内：`.venv`、`frontend/node_modules`、`deps-cache`，不写入系统 Python。

### 8.3 启动与关闭

**启动**：双击 `启动.bat`。

- 默认端口 `8001`；如果端口被占用，脚本会先结束占用该端口的进程。
- 启动后自动打开浏览器 `http://127.0.0.1:8001`；窗口里同时打印局域网地址。
- 服务监听 `0.0.0.0`，同一局域网的其他电脑可用启动窗口里的 IPv4 地址访问；脚本会尝试自动添加防火墙入站规则。

**关闭**：任选一种：

- 双击 `关闭.bat`，结束占用 8001 端口的进程；
- 直接关闭 `启动.bat` 所在窗口。

业务数据留在 `data/contract.db`，下次启动还在。

## 9. 接口约定

- 风格：REST + JSON，统一前缀 `/api`；交互式接口文档在 `http://127.0.0.1:8001/docs`。
- 鉴权：登录成功签发 JWT，请求头 `Authorization: Bearer {token}`；token 过期、用户停用、`auth_version` 不一致都返回 401。
- 公司上下文：服务端从 token 取当前公司；请求头/参数里的 `company_id` 只做一致性校验，不一致返回 403。
- 响应结构：`{ code, message, data }`；成功 `code = 0`。
- 列表响应：`data = { items, total, page, pageSize }`，默认每页 50，最大 500。
- 错误码：`400` 业务校验失败；`401` 未登录/过期；`403` 无权修改或跨公司越权；`409` 乐观锁冲突；`422` 请求参数格式错误。
- 修改：`PUT` 请求体必须携带读取时的 `version`；单条删除 `DELETE /api/{resource}/{id}?version=n`；批量删除请求体 `items: [{id, version}]`。

主要资源与特殊接口：

| 类别 | 接口 |
| --- | --- |
| 鉴权 | `POST /api/auth/login`、`/logout`、`/change-password`、`/forgot-password`；`GET /api/auth/me`；`POST /api/companies/switch` |
| 业务 CRUD | `/api/parties`、`/api/projects`、`/api/purchase-plans`、`/api/contracts`、`/api/orders`、`/api/wms-bills`、`/api/settle-bills`、`/api/invoices`、`/api/other-bills`、`/api/transfer-bills`、`/api/check-bills` |
| 基础资料 | `/api/companies`、`/api/fund-accounts`、`/api/contract-types`、`/api/warehouses`、`/api/goods`、`/api/goods-categories`、`/api/export-profiles` |
| 组织 | `/api/users`、`/api/roles`、`/api/depts`、`/api/posts`、`/api/configs` |
| 合同动作 | `/api/contracts/{id}/supplement`、`/generate-arrival`、`/generate-shipment`、`/generate-input-invoice`、`/api/purchase-contracts/generate-sale-contract`、`/api/contracts/{id}/word` |

### 10.1 上线前验收基线

| 类别 | 检查点 |
| --- | --- |
| 方向 | 销售合同不能生成采购订单/付款单；采购合同不能生成销售订单/收款单；接口拒绝方向不一致 |

### 11.2 当前范围与边界

- 本版本不做审批流、红冲、作废、归档操作；错误单据通过删除重建处理，删除前做引用检查。
- 销售订单、采购订单菜单与页面已移除；订单表为空，后端接口保留。合同、出入库、收付款、发票不依赖订单。
- 其他收入、其他支出菜单与页面已移除；`other_bill` 表为空，后端接口保留；合同毛利仍兼容历史数据。
- 调拨记录、盘点记录只留痕，不自动改库存，也不做 WMS 自动过账。
- 合同毛利是合同金额口径，不含库存成本、期间费用和税费，不等同于财务利润。
- 采购计划同一物料全公司一行，不按月建多行；计划有效期、每月 20 日后导入等规则未启用。
- 提醒不支持批量标记；「忘记密码」不发真实邮件。
- 角色、部门、岗位只是组织字典，不做 RBAC、不控制菜单和数据范围。
- 报关模块是当前版本的扩展能力；形式发票、报关合同等更进一步的关务单据不在本版本内。

## 12. 常见问题

**Q：浏览器打开是空白页或只有接口 JSON？**
A：先确认 `frontend/dist/index.html` 存在；不存在就运行 `安装依赖.bat` 或 `cd frontend && npm run build`，然后重启服务。

**Q：admin / 123456 登录不了？**
A：如果数据库不是全新库，密码可能已被修改，或账号已被停用/锁定。让管理员在「组织管理 → 用户」重置密码；锁定会按安全设置自动到期。

**Q：为什么只有一家公司/没有 zhang、li 账号？**
A：种子账号只在空库首次启动时写入；已有 `data/contract.db` 会保留原数据。需要演示数据时，可由 admin 调用初始化演示数据接口，或备份后重建空库。

**Q：Excel 导入提示「文件解析失败」？**
A：先下载本页模板，确认表头没有被改乱、必填列有值、文件是 `.xlsx`/`.xls` 且不超过 10MB；采购计划还要检查物料编号是否重复。

**Q：生成 Word/Excel 时提示没有模板？**
A：到「基础资料 → 导出模板」为该单据类型新增模板，填写模板绝对地址或上传文件，并设置导出名称规则。

**Q：Word 合同金额或大写不对？**
A：合同金额来自物料明细合计或手填金额；先确认合同金额、税率、明细数量单价正确，再重新生成。模板占位符要和可用字段一致。

**Q：为什么提示库存不足/为什么删不掉入库单？**
A：系统会按「入库之和 − 出库之和」整单重算，结果为负会拒绝保存或删除；如果该入库已生成报关物料/发票，还要先解除报关关联。

**Q：报关发票/清关发票为什么生成不了？**
A：物料必须来自采购入库，且没有生成过同类单据；先确认采购入库已保存、报关物料必填项完整。

**Q：AI 检查没有反应？**
A：到「基础资料 → Deepseek」启用并填写 API Key，点「测试连接」；未配置时只做本地必填检查，不影响业务保存。

**Q：数据放在哪？怎么换电脑？**
A：业务数据在 `data/contract.db`，附件在 `data/uploads`。换电脑时复制整个项目目录，重新运行 `安装依赖.bat`（依赖不随目录复制），再启动即可。

**Q：局域网其他电脑访问不了？**
A：确认使用启动窗口里的局域网 IPv4 地址、两台电脑在同一网段，并放行 8001 端口入站；公司网络策略可能禁止互通。

**Q：怎么彻底重来？**
A：先备份 `data/`，再在「设置 → 安全设置」清空全部数据，或停止服务后删除 `data/contract.db` 和 `-wal`/`-shm` 文件，重启后会重建空库。
