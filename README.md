# 合同管理系统

面向贸易与项目公司的本机业务系统，版本 **2.5.3**。销售和采购各走一条完整链路：客商、合同、订单、出入库、收付款、发票，最后汇总到首页、统计和到期提醒。公司之间的数据互相隔离，切换公司就是切换一整套账。

浏览器打开即可使用。后端同时提供接口和已构建的页面，数据库是项目目录里的 SQLite 文件，不需要单独安装数据库服务。

## 闪光点

**金额不差一分。** 全链路按含税金额计算，使用十进制而不是浮点。每一行先把「数量 × 含税单价」四舍五入到分，作为唯一主值，再反算不含税金额，税额用减法吸收尾差。因此任意单价和数量下，「不含税金额 + 税额 = 价税合计」始终成立，列表合计也只加已经落定的分，不会出现差 1 分。

**单据之间实时勾稽，删改都重算。** 收款、付款、开票、入库、出库保存或删除时，合同已收付、已开票、订单到货发货、库存和采购计划占用在同一个事务里重算。失败则整单回滚，不会先落单一半、事后补数。按实结算的合同按实际出入库数量重算金额，签约数量保持不变。

**并发抢额度时，超了的那一笔会失败。** 两人同时改同一张单据，后保存的人会收到「数据已被他人修改，请刷新」。库存、采购计划、可下单、可开票、阶段可收付这些共享额度另外加行锁：库存 10、两人各出 8，只会成功一笔，库存不会变成负数。

**销售和采购不会串单。** 销售合同只能对接销售订单、收款单、销项发票和销售出库；采购合同只能对接采购订单、付款单、进项发票和采购入库。方向不对，接口直接拒绝。

**改名不改历史，统计也不会丢单。** 客商、物料、员工在单据上只认编号。保存时抄下对方名称和税号；主数据以后改名，历史快照保持原样，筛选和汇总仍按编号，两个同名客商不会串到一起。

**Word 模板直接出正式文件。** 采购合同、销售合同、订单、收付款、发票、出入库都可以按 `需求的模板` 里的 Word 模板填充。模板用 `{{合同编号}}`、`{{对方简称}}` 这类占位符，导出文件名也能按这些字段拼接。金额带千分位，并写成人民币大写。

**Excel 导入可重复、可核对。** 导入分五步：下模板、上传、核对、执行、看结果。同一文件用同一方式再传，直接返回上一次结果，不会重复落库。单元格若以公式字符开头，按文本保存，不执行公式。覆盖他人数据需要单独的导入覆盖权限。

**一套系统，多家公司。** 演示数据预置「星河科技」和「江南建设」。管理员可以看全部公司，普通用户只进入被分配的公司。顶栏切换公司后，列表、统计、业务员和组织资料一起切换。

**谁改的、何时改的，可以追溯。** 密码只存 Argon2id 哈希。连续登录失败会按安全设置锁定。修改密码或管理员重置后，其他设备上的旧登录立即失效。删除是软删除，业务单号永久占用、不回收。关键操作写入操作日志。

## 业务范围

| 菜单 | 做什么 |
| --- | --- |
| 首页 | 销售、采购、未收、合同毛利等卡片，最近合同，到期提醒 |
| 客商 / 项目 / 采购计划 | 客户与供应商共用一套主数据；采购计划按物料编号核销待采购数量 |
| 合同订单 | 销售合同、采购合同、销售订单、采购订单。一合同一张订单 |
| 仓储管理 | 采购入库、销售出库会改库存；调拨记录和盘点记录只留痕 |
| 结算管理 | 按合同阶段收款、付款；待收款、待付款只读汇总 |
| 发票 | 销项、进项按合同未开票数量带出，数量和金额分别校验，不能超开 |
| 统计 | 经营概况、客户、供应商，以及供应商往来明细 |
| 提醒 | 合同到期、发票等待处理，顶栏铃铛显示未处理条数 |
| 基础资料 / 组织 / 设置 | 公司、仓库、商品、用户与角色，登录日志、操作日志、安全设置 |

合同毛利按已签订合同金额计算：销售合同金额 − 采购合同金额 − 其他支出 + 其他收入。它不含库存成本和税费，不是财务利润。未签订、已终止的合同不进入金额统计。

## 安装与启动

在 Windows 上使用。项目自带三个批处理，按下面的顺序操作即可。

| 文件 | 什么时候用 |
| --- | --- |
| `安装依赖.bat` | 第一次使用，或依赖有变动时。装好后不必每次都运行 |
| `启动.bat` | 每次要打开系统时 |
| `关闭.bat` | 用完后停止服务 |

### 1. 准备环境

本机需要能在命令行里直接调用 Python 和 Node.js：

- Python 3.10 或更高版本，并且带有 `pip`
- Node.js，并且带有 `npm`

在命令行执行下面两条，能打出版本号就说明已经就绪：

```bat
python --version
node --version
```

若提示找不到命令，先安装对应软件，并确认安装时勾选了加入 PATH。不需要单独安装数据库。

### 2. 第一次安装

1. 打开项目文件夹（包含 `安装依赖.bat`、`backend`、`frontend` 的那一层）。
2. 双击 `安装依赖.bat`。
3. 等待窗口跑完。它会先读出本项目的绝对路径，再检查 Python / Node.js（没有则尝试用 winget 安装），并把虚拟环境、Python 包、前端依赖和下载缓存全部装到这个项目目录里，然后构建页面并初始化数据库。
4. 看到「完成。以后直接双击 启动.bat」后，按任意键关掉这个窗口。

这一步需要联网。若窗口提示「安装失败，请确认本机已安装 Python 和 Node.js」，回到第 1 步检查 `python` 和 `node` 是否可用，然后重新双击 `安装依赖.bat`。

### 3. 启动项目

1. 在同一个项目文件夹里双击 `启动.bat`。
2. 窗口出现「合同管理系统启动中，浏览器打开 http://127.0.0.1:8001」，并停在服务日志上，表示已经启动。
3. 用浏览器打开 [http://127.0.0.1:8001](http://127.0.0.1:8001)。

使用期间保持 `启动.bat` 打开的窗口不要关。关掉窗口，服务就停了，页面会无法访问。

仓库里已经带有 `data/contract.db`，拉取后就是当前这套业务数据。如果这个文件不存在，第一次启动会自动创建，并写入演示公司和演示业务。

### 4. 登录

打开页面后输入账号密码。演示环境允许使用初始密码。

| 登录名 | 密码 | 说明 |
| --- | --- | --- |
| admin | 123456 | 超级管理员，可切换全部公司，可导入覆盖 |
| zhang | 123456 | 业务员，默认公司为星河科技 |
| li | 123456 | 业务员，默认公司为江南建设 |

`admin` 可在右上角「选择公司」里切换「星河科技」和「江南建设」。切换后，列表、统计和业务员一起换成该公司的数据。两家公司各自有一条可点开的演示业务，合同号示例为 `CG-2026-001`、`XS-2026-001`。

正式部署时设置环境变量 `CONTRACT_DEPLOY_MODE=formal`，管理员首次登录必须修改默认密码。

### 5. 关闭

任选一种方式：

- 双击 `关闭.bat`。它会结束占用 `8001` 端口的进程，看到「关闭完成」即可。
- 或者直接关闭 `启动.bat` 那个窗口。

业务数据留在 `data/contract.db`，下次启动还在。

### 6. 以后每天怎么开

依赖已经装好时，不用再运行 `安装依赖.bat`。直接双击 `启动.bat`，浏览器打开 [http://127.0.0.1:8001](http://127.0.0.1:8001)，用完再双击 `关闭.bat`。

只有在这几种情况下才需要重新双击 `安装依赖.bat`：换了一台电脑、删掉了 `.venv` 或 `frontend/node_modules`、或者更新了 `requirements.txt` 和前端依赖。

### 启动失败时

| 现象 | 处理 |
| --- | --- |
| 窗口提示找不到 `python` 或 `npm` | 安装 Python、Node.js，并确认已加入 PATH，然后重新打开一个新的命令行窗口再试 |
| 提示「安装失败」 | 看窗口里失败的那一行。常见原因是没联网，或 `pip` / `npm` 未装好 |
| 浏览器打不开页面，或只有接口没有界面 | 先确认 `安装依赖.bat` 已成功结束，并且 `frontend/dist` 目录存在，再重新双击 `启动.bat` |
| 提示端口被占用，或页面打不开但窗口一闪而过 | 先双击 `关闭.bat`，再双击 `启动.bat`。本机 `8000` 端口不使用，服务固定走 `8001` |
| 改过端口后地址对不上 | 看 `启动.bat` 窗口里打印的地址，浏览器打开那一个 |

前端单独开发时，先双击 `启动.bat` 让接口在 `8001` 运行，再另开命令行进入 `frontend` 执行 `npm run dev`。开发页面在 [http://127.0.0.1:5173](http://127.0.0.1:5173)，接口请求会转到 `8001`。日常使用不必走这一步。

## 技术构成

| 部分 | 选择 |
| --- | --- |
| 后端 | Python、FastAPI、SQLAlchemy |
| 前端 | Vue 3、Vue Router、Element Plus、Vite |
| 数据库 | SQLite，文件为 `data/contract.db` |
| 文档 | Excel 用 openpyxl；Word 直接填充 docx 模板 |
| 登录 | JWT。服务默认监听 `127.0.0.1:8001` |

可选环境变量：

| 变量 | 作用 | 默认 |
| --- | --- | --- |
| `CONTRACT_PORT` | 服务端口 | `8001` |
| `CONTRACT_DB` | 数据库文件路径 | `data/contract.db` |
| `CONTRACT_JWT_SECRET` | 登录令牌密钥 | 内置本地密钥，正式环境应改掉 |
| `CONTRACT_DEPLOY_MODE` | `demo` 或 `formal` | `demo` |

业务数据 `data/contract.db`、源代码、模板和依赖锁文件会进入仓库。`.venv/`、`pydeps/`、`deps-cache/`、`frontend/node_modules/`、`frontend/dist/` 以及 SQLite 运行时文件不进入仓库。换一台电脑后，先双击 `安装依赖.bat` 在本机装好依赖，再双击 `启动.bat`，打开的就是同一份数据。业务规则、金额公式和验收要点见《合同管理系统开发文档》。
